# Bring your own data

No experimental measurements, property tables, fitted prediction tables, or
scientific example figures are distributed in this code-only release.
Obtain the six datasets from the original sources listed in the main README,
subject to their applicable terms, and prepare the following input files.

By default, files are read from this `data/` directory. Alternatively, keep them
outside the public repository and set `SYMBOLIC_PR_EOS_DATA_DIR` to their root.

```text
data/
  properties.csv
  experimental/C5N2.csv
  calibrated/C5N2.csv
  baselines/zero/C5N2.csv
  baselines/generalized/C5N2.csv
  ... the same files for C6N2, C7N2, C9N2, C10N2, C12N2
```

## CSV schemas

Use these exact headers, without an index column. All numerical rows must be
provided by you; no sample experimental rows are supplied.

### Experimental observations

```csv
T (K),x_N2,y_N2_Exp,P_Exp (MPa)
```

`x_N2` and `y_N2_Exp` are liquid/vapor nitrogen mole fractions. Supply one row
per measured state. Temperature is in K and pressure in MPa.

### Calibrated PR-EOS inputs for learning

```csv
T (K),Tr,x_N2,y_N2_Exp,P_Exp (MPa),P_PR_MPa,y_PR
```

`Tr` is temperature divided by the alkane critical temperature. Pressure and
vapor-composition residuals are computed as experiment minus the calibrated
PR-EOS prediction. Match each row's observation and baseline at the same T/x.
Only retained states with finite baseline predictions should appear here.

The baseline recalculation command can help produce these predictions. Its
calibrated output includes `P_PR_MPa`, `y_PR` and measured columns. Remove failed
rows and add `Tr` from your component properties before using it for training.
This is not an automatic BIP calibration: fixed BIP values are provided in
`configs/calibrated_bip.json`.

### Cached plotting baselines

Zero BIP:

```csv
T (K),x_N2,P_zero_MPa,y_zero
```

Generalized Yang BIP:

```csv
T (K),x_N2,P_yang_MPa,y_yang
```

Additional columns from the baseline solvers are accepted. Nonconverged states
may be recorded as NaN and are logged/omitted from plotted traces.

### Pure-component properties

```csv
Chemical,Tc (K),Pc (bar),Acentric Factor (CoolProp)
```

Supply `N2`, `C5`, `C6`, `C7`, `C9`, `C10`, `C12` as chemical identifiers.
`Pc` is in **bar**; other pressure CSVs use **MPa**. The acentric-factor column
name is retained for compatibility, but you must document your chosen source.
Yang's literature model separately uses its published correlations/constants
in `script/yang2022.py`.

### Proposed predictions for plotting

These are generated by shared training; they are not included in the release.
Required columns:

```csv
system,T (K),Tr,x_N2,P_pred_nn,y_pred_nn
```

Use identifiers `C5N2`, `C6N2`, `C7N2`, `C9N2`, `C10N2`, `C12N2`.
Pass the actual generated `predictions.csv` path to the plotter. It reads the
experimental curves separately from `experimental/`.

## Keep private inputs out of Git

The supplied `.gitignore` excludes CSVs and spreadsheets, generated outputs,
model weights and common binary data formats. Do not force-add these files
without checking their redistribution terms. Newly exported training tables
can also contain measured quantities.
